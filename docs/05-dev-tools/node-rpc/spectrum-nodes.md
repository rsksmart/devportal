[Spectrum Nodes](https://spectrumnodes.com/networks/rsk-rpc) is an RPC provider that runs its own nodes in self operated Tier III data centers. It serves Rootstock Mainnet JSON-RPC.

## Service features

- JSON-RPC access to Rootstock Mainnet (chain ID 30).
- Archive data for historical state.
- Debug and trace methods.
- Self operated Tier III data centers in Malta, the Netherlands, and Canada, plus a bare metal deployment in Singapore.
- SOC 2 Type II attested.

## Get a Rootstock endpoint

1. Sign up at [spectrumnodes.com](https://spectrumnodes.com).
2. Add a Rootstock Mainnet endpoint in the dashboard.
3. Use the endpoint URL in your application for JSON-RPC requests.
