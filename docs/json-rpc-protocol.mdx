# JSON-RPC protocol

Every RSKj method is called the same way: an HTTP `POST` with a **JSON-RPC 2.0**
envelope. Method pages document only what changes between methods — the
positional `params` and the `result`. Everything on this page applies to **all
50 methods** identically.

## Request envelope

| Field | Type | Value |
|---|---|---|
| `jsonrpc` | string | Always `"2.0"` — the protocol version. |
| `method` | string | The method name, e.g. `"eth_call"`. |
| `params` | array | Ordered array of positional parameters. Empty `[]` when a method takes none. |
| `id` | integer \| string | Request identifier, echoed back in the response. |

All four fields are required.

```json
{
  "jsonrpc": "2.0",
  "method": "eth_blockNumber",
  "params": [],
  "id": 1
}
```

## Response envelope

A successful call returns HTTP `200` with the return value in `result`:

```json
{ "jsonrpc": "2.0", "id": 1, "result": "0x137a3c2" }
```

## Error handling

Nodes typically still respond with **HTTP 200** on failure — the error is
carried in the body as an `error` object *instead of* `result`:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32602,
    "message": "invalid argument 0: hex string without 0x prefix"
  }
}
```

Common error codes follow the [JSON-RPC 2.0 specification](https://www.jsonrpc.org/specification#error_object):
`-32700` parse error · `-32600` invalid request · `-32601` method not found ·
`-32602` invalid params · `-32603` internal error.

## Endpoints

Every method can be called two ways: through the **public nodes**, which need no
credentials, or through the **Rootstock RPC API**, which authenticates you with
an API key carried in the URL path.

| Access | Network | Base URL | API key |
|---|---|---|---|
| Public node | Testnet | `https://public-node.testnet.rsk.co` | not required |
| Public node | Mainnet | `https://public-node.rsk.co` | not required |
| RPC API | Testnet | `https://rpc.testnet.rootstock.io/{apiKey}` | required |
| RPC API | Mainnet | `https://rpc.mainnet.rootstock.io/{apiKey}` | required |

`{apiKey}` — the API key segment from the [Rootstock RPC API dashboard](https://rpc.rootstock.io/).
Create a free account and generate a key in [RPC API setup](/developers/rpc-api/rootstock/setup/).

The **Endpoint** picker on every method page switches the samples between these,
so the request you copy is already pointed at the endpoint you use. Paste your
key there once and it applies across the reference — it stays in your browser
and is never sent to Rootstock.

The public nodes are provided by RootstockLabs [for testing purposes](/node-operators/public-nodes/):
they are `HTTP` only — no WebSockets — and rate limited. For production, run
[your own node](/node-operators/setup/node-runner/) or use the RPC API.
